# QuickAnim — 快速动画与渲染助手

一个 Blender 插件，把「常用 K 帧」「MMD 风格摄像机」和「一键渲染」整合进 3D 视图侧边栏，让动画制作更轻松舒服。

> 实测支持 **Blender 5.0.1**（也兼容 3.0 及以上版本）。

## ✨ 功能总览

### 🎬 关键帧区 —— 治「K 帧累」

| 功能 | 说明 |
|------|------|
| 自动记录关键帧 | 一键开关自动插帧（时间轴红点） |
| K 选中 / K 整副骨架 | 当前帧一键插入 位置/旋转/缩放 |
| 复制 / 粘贴 / 镜像粘贴姿势 | 对称动作摆一半就够 |
| 循环（首帧=末帧） | 走路、待机等循环动画一键闭环 |
| 吸附整数帧 / 清理冗余帧 | 手抖、曲线乱一键收拾 |
| 平滑 / 线性缓动 | 一键设置过渡手感 |

### 🎥 摄像机区（MMD 风格）—— 核心亮点

| 功能 | 说明 |
|------|------|
| **MMD 模式** | 视图即摄像机：拖动视角（旋转/平移/缩放）直接移动摄像机，和 MMD 一样的手感 |
| **注册关键帧** | 一键记录镜头位置/旋转/焦距（MMD 的 Register） |
| **开始实时录制** | 移动视角就自动 K 帧，再点一下停止 |
| **贴合画框** | 让视图与摄像机画面框**完全一致**：所见即所得 |
| 切帧自动注册 | 拖动时间轴自动注册镜头关键帧 |
| MMD/录制时自动贴合画框 | 进入 MMD 模式或开始录制时自动执行贴合 |

> **贴合画框** 做了三件事：清除渲染区域裁剪 → 传感器自动匹配输出比例 → 视图框住摄像机边界（等同于相机视图下按 Home）。

### 🖼️ 渲染区 —— 治「渲染麻烦」

| 功能 | 说明 |
|------|------|
| 快速预览 / 草稿 / 成片 | 三档画质一键切换 |
| PNG 序列 / MP4 视频 | 输出格式一键切换（自动适配 Blender 5.0 新媒体类型 API） |
| 切换 GPU 渲染 | 自动识别 NVIDIA / Mac / AMD |
| 选择输出目录 | 渲染结果存放位置 |
| 渲染当前帧 / 渲染动画 | 单帧测试 / 完整渲染 |

## 📥 安装

1. Blender → **编辑 → 偏好设置 → 插件 → 安装** → 选择 `quickanim.py`
2. 勾选启用 **QuickAnim 快速动画与渲染助手**
3. 3D 视图按 **N** → 右侧边栏 → **QuickAnim** 标签页

> Blender 5.0 采用扩展系统，但传统单文件插件（本插件）仍然完全支持，按上述方式安装即可。

## 🚀 推荐工作流

**摄像机动画（MMD 式）**
1. 点「选中摄像机」→「MMD 模式」（画框自动贴合）
2. 第 1 帧摆好镜头 →「注册关键帧」
3. 拖到第 30 帧 → 拖动视角换机位 →「注册关键帧」
4. 播放：中间自动补间；或直接「开始实时录制」边动边录

**角色动画**
1. 起始帧「K 整副骨架」→ 开「自动记录关键帧」摆姿势自动插帧
2. 对称动作摆一半 →「镜像粘贴」
3. 循环动画最后点「循环」
4. 完成后点「平滑」

**渲染**
1. 「快速预览」渲一帧看构图 → 「草稿」渲小段 → 「成片」+ GPU 渲完整
2. 优先 **PNG 序列**（可断点续渲、改单帧不用重渲）
